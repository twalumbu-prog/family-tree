# Our Family Tree & Heritage Chronicle

A simple, private family-tree builder that runs entirely in your browser.

- **Edit anyone:** click a card to change the name, dates, photo or biography.
- **Add relatives:** use the colored "+" buttons or the dashed boxes in the tree.
- **Family stories:** write the history of each side of the family.
- **Print / PDF:** one-click, single-page chart.
- **Share:** changes are saved in *your* browser only. Use **Export Backup** to download a file, and **Import** to open one.

The tree ships with fictional sample data (the "Vance" family). Use the **Reset** button to restore it.

## Develop

```bash
npm install
npm run dev      # local dev server
npm run build    # writes the single-file site to docs/ (served by GitHub Pages)
```
